# Driftstone Synthetic Demo

This directory contains a small fictional showcase for the public Driftstone UI.

It is safe to use for screenshots, README examples, UI regression checks, and
product walkthroughs because it contains no owner history, no private paths, and
no API secrets.

The browser UI uses the same fictional card set through
`ui/synthetic-demo.js`. These files are human-facing projection examples from
that same fictional memory shape:

- `portable-warm/portable-warm-preview.json` shows the machine-oriented shape.
- `obsidian/synthetic-warm-cards.md` shows a readable Markdown projection.
- `notion-ready.csv` shows a table-oriented review projection.
- `spreadsheet/warm-cards.csv` shows a simple spreadsheet inspection view.

These examples are intentionally compact. They demonstrate the product boundary:
the portable Warm shape carries source and review evidence, while Notion,
Markdown, and spreadsheet files are projections.
